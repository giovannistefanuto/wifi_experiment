# Giovanni Inbox

Questa directory contiene materiale aggiunto manualmente dal proprietario del progetto, per esempio immagini, mockup, PDF, ricerche, dataset, codice di esempio, specifiche o output di altri modelli.

Gli agenti non devono scandire automaticamente l'intera directory a ogni task. Devono consultarla soltanto quando:

- Giovanni segnala di aver aggiunto un file;
- il task fa riferimento a materiale esterno;
- un documento del progetto indica esplicitamente una risorsa presente qui.

Dopo aver incorporato una risorsa, non cancellare o spostare automaticamente l'originale. File contenenti dati sensibili, capture, credenziali o identificatori reali non devono essere pubblicati o versionati senza anonimizzazione e autorizzazione esplicita.
